# Mini Proyecto: Gestión de Usuarios y Tareas

## Descripción
Este proyecto es una aplicación sencilla desarrollada en JavaScript para la gestión de usuarios y sus tareas asociadas.  
Permite administrar usuarios, agregar y visualizar tareas, marcar tareas como completadas y eliminar tareas existentes, todo mediante un menú interactivo en la consola.
El programa está orientado a reforzar conceptos fundamentales de programación como arreglos, objetos, ciclos, y manejo de funciones, utilizando entradas y salidas a través de la terminal.

## Funcionalidades principales
- Visualizar usuarios existentes con sus respectivos IDs.  
- Agregar nuevos usuarios.  
- Ver las tareas asignadas a un usuario específico.  
- Agregar nuevas tareas a un usuario.  
- Marcar tareas como completadas.  
- Eliminar tareas de un usuario.  
- Salir del programa de forma segura.

## Uso del programa
1. Ejecutar el archivo JavaScript en un entorno que soporte la función `prompt` (como navegadores o entornos específicos que simulan terminal con inputs).
2. Interactuar con el menú principal ingresando el número de la opción deseada.
3. Seguir las instrucciones para gestionar usuarios y tareas.

## 🧩 Estructura de datos
- El programa utiliza un arreglo de objetos para representar los usuarios, donde cada usuario tiene un arreglo de tareas.
- Cada tarea contiene una descripción, estado (`pendiente` o `completada`) y opcionalmente una fecha.
